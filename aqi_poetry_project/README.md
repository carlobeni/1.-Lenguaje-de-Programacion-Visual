# AQI Monitor - Proyecto Python con Poetry

Sistema de Monitoreo de Calidad del Aire (AQI) y Reverse Geocoding desarrollado en Python aplicando Programación Orientada a Objetos (POO).

## Instalación y Ejecución con Poetry

```bash
# 1. Instalar dependencias
poetry install

# 2. Ejecutar la aplicación mediante script registrado
poetry run start

# O ejecutar directamente el módulo principal en src/
poetry run python -m src.main
```
