## Descripción de la Cátedra

La materia aborda el desarrollo de soluciones software integrales orientadas a sistemas mecatrónicos e industriales modernos. Los contenidos abarcan desde programación orientada a objetos avanzada (POO), protocolos de comunicación y parsing binario de bajo nivel, concurrencia y persistencia de datos temporal (Asyncio + SQLite), hasta la construcción de APIs REST robustas con FastAPI y Pydantic, autenticación basada en JWT, desarrollo de aplicaciones web con Svelte & SvelteKit, visualización gráfica de datos masivos en tiempo real, arquitectura distribuida multinodo y despliegue en producción con Nginx.
